# tagstat

Tag URLs and stat query parts with stable normalization.

**Site:** https://theworker02.github.io/tagstat/

## Install / run

```bash
git clone https://github.com/theworker02/tagstat.git
cd tagstat
node src/cli.js
node --test
```
